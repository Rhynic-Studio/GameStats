# crash 原始对局 log（人工录入的原始形态）

这三份 log 是第一批真实数据，同时作为**录入界面与统计引擎的验收基准**：
把它们录进系统后，系统算出来的数字必须和下面的"解析结果"一致。

---

## log1 — 纯 pick 规则（log 里叫"不完整bp"）

### 原文

```
log1 (刚玩的那一把，规则是不完整bp)
1v1
出现：
艾娅 拔刀 冰女 妮妮 妮娜 阿兰

wsq先手 vs mzy
先手1pick 阿兰
后手23pick 拔刀 艾娅
先手45pick 冰女 妮娜
后手 6pick 妮妮

round1
阿兰 vs 艾娅
先手玩家 选取 round 先攻：先攻
阿兰胜

round2
妮娜 vs 拔刀
上轮失败玩家 选取round先攻：先攻
妮娜胜

wsq 2:0 mzy
wsq胜
```

### 解析结果

| 项 | 值 |
|---|---|
| 规则 | v1 纯pick（池 6，无 ban）|
| 玩家 | side0 = wsq（**BP 先手方**），side1 = mzy |
| 进池 | 艾娅、拔刀、冰女、妮妮、妮娜、阿兰（6 个，全部被 pick，无未选）|
| pick 顺序 | 先 `阿兰` → 后 `拔刀` `艾娅` → 先 `冰女` `妮娜` → 后 `妮妮` |
| 结果 | wsq 2:0 mzy，wsq 胜 |

| 轮 | 先攻选择者 | 先攻方 | side0 出战 | side1 出战 | 胜者 |
|---|---|---|---|---|---|
| 1 | side0 (BP先手方) | side0 | 阿兰 | 艾娅 | **阿兰** (wsq) |
| 2 | side1 (上轮败方) | side1 | 妮娜 | 拔刀 | **妮娜** (wsq) |

**注意**：wsq 的 `冰女` 和 mzy 的 `妮妮` 被 pick 了但**没上过场**（2:0 提前结束）。
所以「被 pick 率」≠「上场率」，统计时必须分开。

## log2 — 旧 BP 规则（已停用，但历史数据要能录）

### 原文

```
log2（旧bp规则）
出现：
妖姬 nagi 芙芙 拔刀 火女 冰女 妮妮 德鲁伊 骇客 怪盗

先手1ban 冰女
后手2ban 骇客
先手1pick 拔刀
后手23pick 德鲁伊 nagi
先手45pick 芙芙 怪盗
后手6pick 妖姬
未选 火女 妮妮

round1
怪盗 vs 妖姬
先手玩家选取round 先攻：先攻
怪盗胜

round2
拔刀 vs 德鲁伊
上轮失败玩家 选取round先攻：先攻
德鲁伊胜

round3 双方弃赛
mzy 1:1 wsq
平局
```

### 解析结果

| 项 | 值 |
|---|---|
| 规则 | v2 旧BP（池 10，先手先 ban、先手先 pick）**已停用** |
| 玩家 | side0 = mzy（BP 先手方），side1 = wsq |
| 进池 | 妖姬、nagi、芙芙、拔刀、火女、冰女、妮妮、德鲁伊、骇客、怪盗（10）|
| ban | 1ban mzy→`冰女`；2ban wsq→`骇客` |
| pick 顺序 | 先 `拔刀` → 后 `德鲁伊` `nagi` → 先 `芙芙` `怪盗` → 后 `妖姬` |
| 未选 | 火女、妮妮 |
| 结果 | mzy 1:1 wsq，**平局**（第 3 轮双方弃赛）|

| 轮 | 先攻选择者 | 先攻方 | side0 出战 | side1 出战 | 胜者 |
|---|---|---|---|---|---|
| 1 | side0 (BP先手方) | side0 | 怪盗 | 妖姬 | **怪盗** (mzy) |
| 2 | side1 (上轮败方) | side1 | 拔刀 | 德鲁伊 | **德鲁伊** (mzy) |
| 3 | — | — | — | — | 双方弃赛 |

**注意**：第 2 轮先攻方（wsq 的拔刀）**输了** —— 先攻不等于优势，这正是"先攻方胜率"值得统计的原因。
**注意**：需要 `弃赛` 这种非胜负的轮结果，以及系列赛级 `平局`。

## 三套规则对比

| | log1 | log2 | log3 |
|---|---|---|---|
| 规则 | v1 纯pick | v2 旧BP（停用）| v3 现行BP |
| 池大小 | 6 | 10 | 10 |
| ban | 无 | 先手1 + 后手1 | 先手1 + 后手1 |
| pick 顺序 | 先 后后 先先 后 | 先 后后 先先 后 | **后** 先先 后后 先 |
| 每方 pick | 3 | 3 | 3 |
| 未选数 | 0 | 2 | 2 |
| 结果 | 2:0 | 1:1 平局 | 进行中 |

> v3 与 v2 的差别**只有 pick 起点**：v2 由 BP 先手方先 pick，v3 改由后手方先 pick。
> 这印证了"BP 规则 = 一串槽位模板"的建模方式是对的。
